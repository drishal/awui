- `npm run smoke` runs the real Pi, omp, Hermes, Claude Code, Codex, Grok Build, and DeepSeek Harness: discovery, a session with the harness's normal tools, config, session listing, and Pi resume-after-restart (from a session written by Pi's own `SessionManager`). It never calls a model unless `SMOKE_MODEL=<provider/model>` names a model already configured in Pi, omp, and Hermes; then it also runs prompt → stream → stop → resume. Claude Code takes `SMOKE_CLAUDE_MODEL` instead (e.g. `haiku`), Codex takes `SMOKE_CODEX_MODEL` (e.g. `gpt-6-luna`), Grok Build takes `SMOKE_GROK_MODEL` (e.g. `grok-4.7`), and DeepSeek Harness takes `SMOKE_DSH_MODEL` as its full `provider/model` key (e.g. `deepseek-official/deepseek-v4-flash`). Prefer a local model so it costs no tokens. It never starts a model server. Hermes needs a gateway interpreter it can find: `HERMES_PYTHON` while that interpreter imports `tui_gateway`, otherwise the launch command the `hermes` launcher names for itself, otherwise `python3` (see [Hermes](architecture.md#hermes)).

**NixOS.** Playwright browsers come from nixpkgs through `PLAYWRIGHT_BROWSERS_PATH`, and `@playwright/test` is pinned to the same version (1.63.0). Never run `npx playwright install`. Check the version with:

```bash
nix eval --raw ~/dotfiles/NixOS#nixosConfigurations.$(hostname).pkgs.playwright-driver.version
```
